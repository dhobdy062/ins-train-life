# Cream No Sugar CTA Path Decision Sheet

_Last updated: 2026-04-22_

## Purpose

Lock the version-one CTA logic before Cream No Sugar gets pushed harder.

The goal is simple:
- stop the page from splitting high-value manager traffic into the wrong path
- decide when `Start a Sample Call Free` should be shown
- decide when `Book a Team Demo` should lead
- keep the first launch aligned with the real first buyer

This is not final design copy.
It is the conversion-routing decision sheet for the current launch phase.

---

## Core rule

Do not let the easier CTA weaken the better buyer path.

Cream No Sugar's best first buyer is:
- IMO leaders
- agency managers
- agency owners
- teams with roughly 3 to 20 active producers

That means the default launch should optimize for:
**team demo conversations**
not maximum free sample-call volume.

---

## Core decision

**Recommendation:** for manager-focused traffic, make `Book a Team Demo` the primary CTA.

Keep `Start a Sample Call Free` as a secondary path for:
- colder visitors
- curious solo reps
- lower-friction self-education
- supporting proof that the product is real

This keeps the high-value buying path clear without fully removing the lower-friction trial path.

---

## Why this is the right decision now

### 1. The current best buyer is team-based
The active offer is not mainly a solo-rep subscription.
It is a 5-seat pilot for team leaders.

If the homepage leads with free sampling too hard, it can:
- attract weaker-fit solo traffic
- reduce urgency to book a manager demo
- make the product feel more like a rep toy than a team training workflow

### 2. The demo is where the manager value lands
The strongest manager proof is not just:
- the AI call exists

It is:
- how the objections work
- how scoring works
- how a manager reviews performance
- how a 5-seat pilot would run

That value lands better in a short demo than in a self-serve sample call alone.

### 3. Free sample access is still useful, just not as the lead path for the best buyer
A sample call can help with:
- curiosity reduction
- basic product believability
- solo-rep interest
- lower-friction social or organic traffic

But it should support the main conversion path, not replace it.

---

## Recommended CTA structure by traffic source

## 1. Direct outreach to managers / IMO leaders
### Primary CTA
**Book a Team Demo**

### Secondary CTA
Optional light-text link to sample call, but do not feature it equally.

### Why
This traffic is already problem-aware enough to evaluate the workflow.
The real goal is a sales conversation, not unguided exploration.

### Best implementation
- manager one-pager
- outbound emails
- DM follow-up
- warm intro follow-up
should all push to `Book a Team Demo` first.

---

## 2. Homepage traffic from mixed sources
### Primary CTA
**Book a Team Demo**

### Secondary CTA
**Start a Sample Call Free**

### Why
The homepage can handle broader traffic, but the page should still reflect the current launch priority.
The higher-value buyer should not have to guess what the intended next step is.

### Best implementation
- hero CTA 1: `Book a Team Demo`
- hero CTA 2: `Try a Sample Call`
- manager-focused sections repeat `Book a Team Demo`
- sample-call CTA can appear again lower on page for self-serve visitors

---

## 3. Social content or curiosity-driven traffic
### Primary CTA
Depends on the post angle.

If the post is about:
- manager pain
- roleplay time
- team coaching
- wasted leads across a downline

Use:
**Book a Team Demo**

If the post is about:
- product realism
- objection practice experience
- "see how it feels"

Use:
**Start a Sample Call Free**

### Why
Social traffic is less uniform.
The CTA should match the promise made in the content.

---

## 4. Solo-rep or lower-fit traffic
### Primary CTA
**Start a Sample Call Free**

### Secondary CTA
Optional `Book a Team Demo` only if the rep could influence a manager.

### Why
Solo reps are not the first launch priority, but sample-call access can still collect useful interest without distracting manager-focused conversion paths.

---

## Best destination logic

## Path A: Book a Team Demo
This path should go to:
- calendar booking page
- short manager-fit explanation
- light qualification form

### Ideal page message
- this is for life insurance team leaders
- the demo shows the training workflow and scoring layer
- the point is to evaluate fit for a 5-seat pilot

### Best form fields
- Name
- Email
- Agency / team
- Role
- Team size
- Biggest training bottleneck right now

### Avoid
- long procurement questions
- heavy technical questions
- generic contact form feel

---

## Path B: Start a Sample Call Free
This path should go to:
- a simple self-serve product taste
- one realistic scenario
- a clear post-sample CTA into team demo or follow-up

### Ideal experience
The sample call should prove:
- the call feels real enough
- objection handling matters
- this is more than a static training tool

### What must happen after the sample
Do not let the sample call end in a dead end.

After the sample, the user should see:
- `Want to use this with a team? Book a Team Demo`
- short manager value reminder
- light email capture or follow-up option if useful

### Core rule for sample-call flow
The sample call is a proof device.
It is not the whole conversion system.

---

## Recommended page-level CTA behavior

## Hero section
If the current page is manager-first, use:
- primary CTA: `Book a Team Demo`
- secondary CTA: `Try a Sample Call`

## Manager section
Use only:
- `Book a Team Demo`

The manager section is not the place to split focus.

## Pricing section
If pricing stays visible, use:
- `Book a Team Demo` near team plans
- optional `Try a Sample Call` near solo or exploratory language only if solo traffic still matters

## Final CTA section
Use:
- primary: `Book a Team Demo`
- secondary: `Try a Sample Call`

The end of the page should reinforce the current launch priority.

---

## What to avoid

Avoid these mistakes:
- making both CTAs look equally important in every section
- letting a manager-focused pitch end in a self-serve solo-style action
- using the sample call as the default next step for warm manager traffic
- treating curiosity volume like proof-of-demand quality
- forgetting to route sample-call users toward the real team offer

---

## Fast implementation recommendation

If Don wants the cleanest version-one launch path, do this:

### Homepage / marketing page
- make `Book a Team Demo` primary
- keep `Try a Sample Call` secondary

### Outreach assets
- use only `Book a Team Demo`

### Sample-call flow
- add a strong follow-on CTA into manager demo

This is the simplest setup that matches the current business goal.

---

## If Don wants an even tighter launch test

The stricter option is:
- remove `Start a Sample Call Free` from outbound and manager-facing assets entirely
- keep it only on the site as a secondary exploratory path
- judge demand mainly by demo bookings, not sample-call usage

This is probably the better choice if the goal is clean signal from real buyers.

---

## Best final reminder

Cream No Sugar does not need the most clicks right now.
It needs the right conversations.

If the launch is team-first, the CTA system should feel team-first too.
